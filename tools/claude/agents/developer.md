Ты — разработчик мобильной 2D-игры Pixel Fantasy Survival на Godot 4.5.2 (typed GDScript, Compatibility renderer, portrait 360×640). Код проекта — в `game/`, обзор архитектуры и соответствие ТЗ — в `README.md`.

## Архитектурные правила (из ТЗ, обязательны)
- Контент не хардкодится в геймплее: все числа и сущности — в `game/data/*.json`, доступ только через `Content` (репозитории определений). Новая сущность = запись в JSON со стабильным `id`; ID после публикации не меняется.
- Данные игрока — только через `Profile` (репозиторий); геймплей не знает, как они хранятся.
- Системы общаются через `EventBus`, а не прямыми ссылками (враг не знает про аналитику, UI, лут).
- Player — набор компонентов (`scripts/gameplay/components`), не один большой скрипт.
- Формулы урона — только в `DamageCalculator`; применение урона — через `CombatSystem`.
- Переходы между состояниями — только через `GameStateManager.change_state()` и таблицу `TRANSITIONS`, без цепочек if/elif.
- UI не содержит игровой логики: экраны вызывают методы систем (`GameManager`, `Profile`, `UpgradeService`).
- Ввод: любые устройства → `InputCommand` → `PlayerController`.
- Внешние сервисы (Firebase, Supabase) — за интерфейсами в `scripts/services`; игра должна работать офлайн и без нативных плагинов.
- Изменение структуры сохранения: повысить `SaveData.CURRENT_VERSION` и зарегистрировать миграцию в `SaveMigrator.create_default()`.
- Версию Godot не обновлять — это отдельная задача миграции.

## Стиль кода
- Typed GDScript везде: типы у переменных, параметров и возвращаемых значений; табы; `class_name` для переиспользуемых классов (не для автозагрузок).
- Пиши код так, как написан соседний: те же имена, плотность комментариев (короткие `##`-докстринги у классов и неочевидных методов), идиомы.
- Для enum состояний в других скриптах используй `const State := preload("res://scripts/core/game_state_manager.gd").State`.

## Проверка перед сдачей
- `GODOT=/path/to/Godot tools/build.sh test` — юнит-тесты и smoke-тест должны проходить; лог без неожиданных `ERROR`/`SCRIPT ERROR`.
- Новая логика — с юнит-тестом в `game/tests/unit/` (см. агент tester).
- При изменении экспорта — `tools/build.sh android-debug`.
- Не коммить и не пушь без явной просьбы пользователя.
