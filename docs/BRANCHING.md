# Ветки и релизы: проектные дополнения

Основной документ — `docs/GIT_WORKFLOW.md` (инструкция владельца от 2026-10-18): `main` — стабильная ветка интеграции, работа в `feature/*` и `fix/*` с интеграцией через PR, релиз — временная ветка `release/X.Y.Z`, срочные правки — `hotfix/*` от тега, у каждого релиза аннотированный тег `vX.Y.Z`. Прежняя модель (долгоживущие `release/N.x` по мажорам, `minor/N.M`, перенос `main` в релизные ветки) **отменена**.

## Применение в проекте
- Коммиты: `type(scope): description` (`feat(hud): ...`), типы из `GIT_WORKFLOW.md` §8.
- Версии: SemVer, смысл приращений — `docs/VERSIONING.md` (major — механика или дизайн, minor — пачка обновлений, patch — исправления). Версию релиза подтверждает владелец; ранние версии `0.x.y` по `GIT_WORKFLOW.md` §4 — вопрос к владельцу (сейчас 1.0.0).
- Идентификация сборки: `GAME_VERSION` (`game_config.json`, `project.godot`, `export_presets.cfg`), `BUILD_NUMBER` и `GIT_COMMIT` — не выдумывать (§7).
- Без явного разрешения владельца: merge в `main`, push, force-push, `reset --hard`, удаление веток и тегов, создание или публикация релиза, загрузка сборок (§9.4).
- Перед работой: `git status`, `git branch --show-current`, `git log --oneline -10`; в конце задачи — итоговый отчёт по §9.6.
- Тесты: `GODOT=/Applications/Godot.app/Contents/MacOS/Godot tools/build.sh test`.

## Состояние на 2026-10-18
- Первая версия — **0.1.0** (прототип); ранее была 1.0.0, тег `v1.0.0` удалён и заменён `v0.1.0`. Релизные ветки старой модели (`release/1.x`) удалены.
- Тег `v0.1.0` стоит на коммите `main`, в котором версия 0.1.0 записана в `game_config.json`, `project.godot` и `export_presets.cfg`.
