# История версий

## 1.0.0 — 2026-10-17
- Горизонтальная ориентация (640×360), плавающий стик в левой нижней области, невидимый без касания.
- HUD: полосы здоровья и опыта по 1/3 ширины без чисел, иконки сердца и маны.
- Спавн врагов отодвинут (440–500 px) под широкие экраны; исправлена пустая полоса здоровья в начале боя.
- Новые горизонтальные скриншоты; графика перенесена в Figma, схемы механик остаются в Miro.
