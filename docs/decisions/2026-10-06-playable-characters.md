# Играбельные персонажи — решения

| Решение | Выбор | Почему | Пересмотреть, когда |
|---|---|---|---|
| Состав | Все пять классов с ключарта: воин, маг, хилл, лучник, охотник | Решение владельца продукта (расширение объёма MVP, где по ТЗ один персонаж) | при нехватке времени до релиза — урезать до трёх |
| Различия классов | У каждого своя базовая атака и свой навык | Классы должны ощущаться по-разному, а не только цифрами | — |
| Воин | Удар по дуге (как сейчас) + «Тяжёлый удар» (урон вокруг) | Уже реализовано | — |
| Маг | Магический снаряд с небольшим взрывом + «Метеор» (урон по области у ближайшего врага) | Дальний бой с уроном по площади | — |
| Лучник | Быстрые стрелы на большую дальность, пробивают одного врага + «Залп» (веер стрел) | Чистый дальний урон | — |
| Хилл | Святой снаряд средней дальности + «Волна света» (лечит себя и ранит врагов вокруг) | В одиночной игре лечить можно только себя; самый живучий герой при низком уроне | — |
| Охотник | Бросок ножа на ближней дистанции + «Зов волка» (волк-спутник на время, атакует сам) | Отличается от лучника; фантазия класса — питомец | если спутник станет постоянным |
| Открытие | Все персонажи доступны сразу | Решение владельца продукта | при добавлении мета-прогрессии |
| Тренировки | Общие для всех героев | Вложенное золото не «сгорает» при смене героя | если понадобится прокачка конкретного героя (миграция сейчас не нужна) |
| Тип атаки в данных | Поле `attack` в `characters.json`: `melee_arc` или `projectile` с параметрами снаряда | Данные, а не код на каждого героя | — |
| Навыки в данных | Тип эффекта в `skills.json`: `aoe_damage`, `target_aoe`, `volley`, `heal_wave`, `summon` | Новый навык того же типа добавляется данными | при появлении статус-эффектов |
| Улучшения навыков | Run-улучшение навыка предлагается, только если у героя есть этот навык | Иначе выпадает бесполезный выбор | — |

## Отложено / предположения
- Статус-эффекты (замедление, оглушение) — не входят; навыки только наносят урон, лечат или призывают.
- Баланс характеристик новых героев — **предварительный**, проверяется плейтестом.
- Спутник охотника неуязвим и не получает урон — **предположение** для простоты; пересмотреть, если окажется слишком сильным.
